# 🧑‍💼 Cashier Intelligence — Интеллектуальная система аналитики кассиров

Интеллектуальная платформа мониторинга, учёта KPI, оценки нагрузки и анализа штатного состояния кассиров коммерческого банка.

---

## 🎯 Назначение системы

Система **Cashier Intelligence** предназначена для автоматической обработки операционных Excel-отчётов кассиров, учёта рабочих минут, оценки эффективности (БЭК / ФРОНТ операции), а также автоматического мониторинга штатного состояния (отпуска, декреты, временные замещения).

### Ключевые возможности:

| Возможность | Описание |
|---|---|
| 📊 **KPI & Аналитика кассиров** | Учёт количества операций, рабочих минут, распределения БЭК vs ФРОНТ |
| ⚡ **Оценка нагрузки (%)** | Расчёт загруженности кассиров и отклонений от нормы |
| 📋 **Реестр штата и статусов** | Учёт находящихся в трудовом отпуске (`мехнат.тат.`), декрете (`декрет2`), на временном замещении (`вакт.`) |
| 📥 **Гибкий Excel-импорт** | Поддержка отчётов с многострочными шапками, автоопределение колонок A:AV |
| 🔍 **Фильтрация и поиск** | Фильтрация по роли (Бэк/Фронт/Смешанный), должности, статусу и табельному номеру |
| 👤 **Профиль кассира** | Углублённая детализация каждого сотрудника со структурой выполненных операций |

## 🛠️ Технический стек

```
Backend        FastAPI + uvicorn
Processing     openpyxl, re, python-multipart
Database       SQLite (cashiers.db)
Frontend       Vanilla HTML5 / CSS3 + Chart.js + Lucide Icons
Инфраструктура Python 3.10+
```

## 🚀 Быстрый запуск

### 1. Запуск на Windows:
Двойной клик по скрипту:
```cmd
start.bat
```
*(Или `start_new_pc.bat` для портативного запуска без установленного Python)*

### 2. Запуск на Linux / macOS:
```bash
chmod +x run.sh
./run.sh
```

### 3. Ручной запуск:
```bash
pip install -r requirements.txt
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

## 📡 API Endpoints

- `POST /api/cashiers/import` — Загрузка операционного отчёта KPI из Excel
- `POST /api/cashiers/import-status` — Загрузка реестра штата и статусов кассиров из Excel
- `GET /api/cashiers/analytics` — Получение списка, рейтинга и структуры операций кассиров
- `GET /api/cashiers/{report_id}` — Получение детальной карточки кассира
